# MottuChallenge - Plano de Testes (Sprint 4)

## Sobre o Projeto
Este repositório contém o **plano de testes manuais e automatizados** do sistema **MottuChallenge**, desenvolvido durante a Sprint 4 da disciplina de **Quality Assurance & Compliance**.

O sistema tem como objetivo o **gerenciamento de pátios e motos**, auxiliando no controle de localização, manutenção e clusterização de veículos, com integração à API principal da aplicação (`MottuChallenge.API`).

Os testes garantem que os **serviços, controllers e integrações** (banco de dados, autenticação JWT e endpoints REST) funcionem corretamente.

---

## Objetivos do Projeto de Testes
- Validar manualmente as principais funcionalidades do sistema via **Azure Boards**.
- Garantir que os endpoints retornem os **status HTTP e dados esperados**.
- Comprovar o funcionamento dos testes **automatizados** via vídeo de execução.
- Integrar a gestão de qualidade com as ferramentas **GitHub** e **Azure DevOps**.
